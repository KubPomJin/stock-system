# StockKeep — ระบบจัดการสต๊อกสินค้า

Desktop stock management for a Thai construction-materials shop. Append-only
stock ledger with full audit trail, multi-location stocktakes, warehouse zone
map, and dot-matrix document printing. Electron + TypeScript + SQLite.

> UI ภาษาไทยทั้งหมด · โค้ดและชื่อตารางเป็นภาษาอังกฤษ · ใช้งานจริงอยู่ที่ร้าน

---

## ทำไมถึงเขียนขึ้นมา

ระบบเดิมที่ร้านใช้ (Real 4POS) เก็บสต๊อกเป็น **ตัวเลขเดียวที่แก้ทับได้** พอยอดเพี้ยน
ก็ไม่มีใครบอกได้ว่าเพี้ยนตอนไหนหรือใครแก้ จนเกิดยอดติดลบโดยไม่มีร่องรอย

StockKeep แก้ปัญหานั้นด้วยการทำให้สต๊อกเป็น **ledger** — ทุกการเปลี่ยนแปลงคือแถวใหม่
ยอดคงเหลือคือผลรวมของการเคลื่อนไหว **ไม่มีที่ไหนในโปรแกรมที่ UPDATE ยอดโดยตรง**

## ฟีเจอร์

| หน้า | ทำอะไร |
|---|---|
| แดชบอร์ด | KPI, แจ้งเตือนของต่ำกว่าขั้นต่ำ / ติดลบ |
| สินค้า | หลายระดับหน่วย (พาเลท/กล่อง/ชิ้น), ราคาหลายชั้นตามสิทธิ์, เลือกคอลัมน์ที่จะดูได้ |
| รับสินค้า / เบิกของ | เอกสารรับของ, โยกของระหว่างคลังกับหน้าร้าน |
| ตรวจนับสต๊อก | พิมพ์ใบนับ A4 หลายคลังในใบเดียว, กรอกกลับแยกตามหน่วย, เก็บเป็นรอบพร้อมผู้นับ |
| ประวัติสต๊อก | ดูรอบตรวจนับแบบตาราง, ออก PDF, **แก้ย้อนหลังได้โดยไม่ทับของเดิม** |
| ผังโกดัง | ค้นหาว่าของอยู่โซนไหน + ผังกดได้ |
| ใบสั่งสินค้า | พิมพ์ฟอร์มลงกระดาษต่อเนื่องบนเครื่องดอตแมทริกซ์ |
| ผู้ใช้งาน | สิทธิ์ 3 ระดับ + สำรอง/กู้คืนฐานข้อมูล |

## การตัดสินใจเชิงออกแบบ

**สต๊อกเป็น ledger เท่านั้น** — ยอดคงเหลือ = `SUM(stock_movements.qty_change)`
การแก้ย้อนหลังทุกกรณี (รวมถึงการแก้รอบตรวจนับที่คีย์ผิด) ออกเป็นรายการ `ADJUST`
ตามส่วนต่าง แล้วผูกกลับไปยังรอบเดิม — ประวัติเดิมไม่เคยถูกลบหรือเขียนทับ

**กรองราคาที่ main process ไม่ใช่ที่ UI** — พนักงานระดับ 1 ไม่เคยได้รับต้นทุน
ราคาช่าง หรือราคาส่งผ่าน IPC เลย ไม่ใช่แค่ซ่อนไว้ในหน้าจอ

**ทุกจำนวนเก็บเป็นหน่วยฐาน** แปลงเป็นกล่อง/พาเลทตอนแสดงผลเท่านั้น —
แต่ตอนตรวจนับจะเก็บ *สิ่งที่นับได้จริงแยกตามหน่วย* ไว้ด้วย เพราะ "4 กล่อง + 2 ชิ้น"
กับ "202 ชิ้น" เป็นคนละการนับ แม้ยอดรวมจะเท่ากัน

**โซนโกดังไม่ใช่มิติของสต๊อก** — เป็นตัวช่วยหาของอย่างเดียว ไม่แตะ ledger

## Tech stack

Electron · TypeScript · SQLite (better-sqlite3) · electron-vite + electron-builder ·
vanilla HTML/CSS/JS ฝั่ง renderer (ไม่มี framework)

## เริ่มใช้งาน

```bash
npm install
npm run dev        # โหมดพัฒนา
npm start          # รัน build ที่ compile แล้ว
npm run dist       # สร้าง installer .exe ใน release/
npx tsc --noEmit   # ตรวจ type
```

เข้าระบบครั้งแรก `admin` / `admin123` — **เปลี่ยนรหัสผ่านทันทีหลังติดตั้ง**

ฐานข้อมูลอยู่ที่ `%APPDATA%\stockkeep\stockkeep.db` (นอก repo เสมอ)
สร้างเองอัตโนมัติตอนเปิดครั้งแรก และปรับโครงสร้างด้วย `runMigrations()` ทุกครั้งที่เปิด
